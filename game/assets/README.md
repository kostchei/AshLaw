# Game assets

Runtime art, audio, fonts, and imported asset bundles belong here.

`shape-packs/flare-starter/` is the first Shape Pack v1 bundle. It contains a
desaturated Flare knight, goblin, and shortsword plus an AshLaw chest. The
manifest records atlas rectangles, frame origins and durations, physical
footprints, heights, sorting flags, and packed 1-bit alpha masks.

The adapted Flare art is CC-BY-SA-3.0-or-later and carries its own attribution
and licence inside the pack. Do not copy a community sprite into this directory
without recording its source, revision, authors, and licence in the pack.

See `docs/shape-pack-v1.md` for the format and reproducible import command.
